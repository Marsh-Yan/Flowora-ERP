# Flowora ERP 2.0.0 M5

> 历史阶段说明：下文测试数量、V15 演练和勾选项是 M5 当时结果。2026-09-29 审计发现的缺陷已通过 R0–R4 分阶段整改；当前代码包含 V18，最新验证入口见 [release-verification.md](../development/release-verification.md)，实际覆盖与未完成门禁见 [audit-verification.md](../development/audit-verification.md)。本记录不宣告 GA，不作为当前正式库版本状态证明。

M5 完成 2.0 的分析、升级、生产加固和发布准备：

- 服务端角色工作台、趋势分析、授权跨组织汇总和保存视图。
- 带权限、审计、过期清理、行数上限和 CSV 注入防护的异步导出。
- 管理员诊断、Prometheus 指标与 outbox/导出/流程告警。
- v1 读取兼容、v1 业务写入 426、前端业务调用统一迁移到 v2。
- V15 将旧应收/应付映射为只读影子单据且不生成凭证，并提供升级、备份与恢复工具。
- 生产 profile、安全响应头、同源反代、容器编排、健康检查和运维手册。
- 前端路由级拆包、角色权限导航、响应式与可访问的工作台/分析页面。

已完成 79 项后端测试、前端规范/单元测试/生产构建，以及空库和 V14 副本两次隔离迁移演练。真实数据库继续保持 V14，等待正式切换批准。
