# Flowora-ERP 1.0.0 发布说明

状态：Phase 10 发布候选，待最终人工验收。

## 本版本交付

Flowora-ERP 1.0.0 是单组织演示版 ERP，覆盖以下可演示闭环：

- 平台登录、会话、粗粒度角色权限、组织边界、统一错误和审计追踪。
- 客户、供应商、商品/服务、仓库、币种、汇率、税率和科目等主数据。
- 待办、审批、站内通知、评论和活动时间线。
- 采购申请、采购订单、入库、多仓库存、调拨、盘点、库存调整和移动加权平均。
- 销售报价、销售订单、部分出库、应收和收款。
- 总账、凭证、应收应付、收付款、会计期间、试算平衡和基础财务报表。
- 项目、里程碑、任务、工时、费用、预算和销售订单关联。
- 工作台真实业务指标、全局搜索、导出、打印、中英双语、时区和多币种显示。
- 可重置的确定性演示数据、幂等保护、冲突错误处理和发布文档。

## 已知限制

- 1.0 使用内存演示账号；数据库中的演示用户行仅用于审计关系，不是生产认证方案。
- 真实 MySQL/Redis 端到端验证需要本机数据库凭据，凭据不提交仓库，也不写入 CI。
- 前端主 bundle 当前超过 Vite 的 500 kB 提示阈值，不影响构建，但 2.0 应继续拆分代码块。
- 1.0 不包含生产部署、密钥托管、备份恢复和高可用运维方案。
- 业务数据虽然预留组织字段，但 1.0 固定为单组织演示版。

## 2.0 路线图

以下内容明确不纳入 1.0，将在 2.0 评估和排期：

- 可视化流程设计器和细粒度岗位权限。
- 退货/退款、批次/序列号/库位。
- 国际贸易级税务、多法人和更完整的多币种核算。
- 邮件、SSO、附件和外部系统集成。
- MRP、生产计划和完整项目财务。
- 生产级认证、密钥托管、部署、备份恢复、监控和高可用。
