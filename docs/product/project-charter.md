# Flowora ERP 项目章程

## 产品定位

Flowora ERP 是面向现代中小企业的国际化 ERP Demo，强调：

1. 采购、库存、销售之间的业务闭环。
2. 审批、待办、通知和操作审计。
3. 中英文、多时区、多币种的数据表达。
4. 适合 GitHub 展示的工程质量与产品完成度。

## 首期目标

首期交付一个可运行的 ERP 工作台和核心业务闭环：

- 登录、角色和权限基础。
- 工作台与全量模块导航。
- 采购审批、入库、库存变化。
- 销售订单、出库、库存变化。
- 流程任务箱和审计时间线。

财务深度核算、制造 MRP、外部系统集成和线上部署属于后续阶段。

## 产品语言

- 默认语言：中文（`zh-CN`）。
- 支持语言：英文（`en-US`）。
- 组织级配置：语言、时区、货币。
- API 不返回面向用户的固定中文文本，使用错误码、消息键和参数。

## 创新主线

Flowora 的差异化重点不是堆叠模块，而是将 ERP 业务动作组织成可追踪的流程：

- 业务单据驱动审批任务。
- 每个关键动作产生可审计的时间线。
- 待办、通知和业务状态关联。
- 后续可扩展为可配置流程模板。
