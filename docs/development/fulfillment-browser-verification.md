# 采购入库与销售履约浏览器验证

## R5-R（2026-10-03）

本阶段使用独立组织与合成客户、供应商、商品、仓库，经普通页面完成原生订单创建/确认、兼容入库/发货、部分履约及取消。实例仅监听本机，未改动业务库。

### 修复

采购入库打开时同时选择订单、真实来源行、仓库、剩余数量和成本，避免订单选择框为空而其他字段已填的状态。选择订单后同步整组字段；无有效来源行或无剩余数量时不可打开入库。提交前验证正数、有限数量、剩余上限及非负成本，请求进行中阻止重复保存和关闭，失败保留表单供明确重试。

每次打开重置表单，关闭销毁输入组件，部分入库后重新打开显示最新剩余数量。弹窗宽度随视口收缩，在390px视口保持全部输入和保存操作可见。销售待履约统计排除已取消订单，保留草稿和有效订单的原有统计口径。

### 实证

| 普通页面操作 | 页面及数据库结果 |
| --- | --- |
| 采购4件、单价8，确认并一次入库 | RECEIVED，4/4 |
| 销售3件、单价10，确认后先发1再发2 | PARTIALLY_FULFILLED 1/3，然后FULFILLED 3/3 |
| 采购2件、单价8，确认后先入1再入1 | 两次均直接使用默认订单；重新打开剩余1，最终RECEIVED 2/2 |
| 草稿销售1件后取消 | CANCELLED 0/1；待履约统计由1降至0 |
| 全部采购入库完成 | 无可入库订单，入口禁用 |

组织范围只读SQL核对：3张入库、2张发货、5条canonical库存流水；库存3件、平均成本8、价值24；5张凭证借贷各72且无不平衡凭证；3张应付合计48、已付0。取消测试不改变上述库存与凭证。

本地Web六文件61项通过，lint、vue-tsc和生产构建通过。新增9项组件测试覆盖默认选择/切换、缺行/空列表、刷新后无候选、重复保存、失败重试、部分入库重开及取消统计；使用组件桩隔离选择组件，真实交互另由上述浏览器流程验证。
