# 退款页面验收（R6-F）

财务运营工作台新增退款管理。finance:view且组织ALL范围可查看全部日期退款历史；创建另需finance:create，过账另需finance:post，使用原收付款的实际元数据，不要求master:view。单独重读完整收付款列表，候选只接受当前组织已过账普通收款/付款，原币种、本位币、会计汇率及日期完整。支持本位币与外币，沿用原汇率，不允许页面另填汇率或回溯记账。

可退金额按原金额减核销金额，再减全部DRAFT/POSTED来源退款；无来源历史退款使同交易方同币种候选余额归零。草稿即占用；支持分次退款、现金或同币种银行账户。正数最多4位金额、实际来源、参考信息长度、明确确认及完整读取后才可保存。金额或账户等变更后须重新确认。保存后历史显示DRAFT，须另选实际退款草稿和当前版本，确认现金/银行及往来记账后再过账。退款沿用PR55后端余额锁、期间和来源约束。

相同内容在结果不确定后明确重试复用幂等键，即使服务端已占用余额也可找回原草稿；内容改变使用新键。写操作无自动重试，等待中禁止重复与关闭；错误后重读历史。关闭、组织/权限切换或卸载丢弃迟到读取和动作回调。读取失败暂停创建和过账；只读/过账用户不读取银行列表。
