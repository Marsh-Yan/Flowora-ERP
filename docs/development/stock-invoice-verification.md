# 库存来源开票与销售币种验证

验证日期：2026-10-05。基线为 PR47 合并后的 main `d08f4efc39dbee6803fdfb8f5ef77490c205cd19`。

## 变更与契约

正式发票简易表单原先仅发送空sources，不能在页面关联入库/发货开票。本批新增“从入库 / 发货开票”入口和组织内只读 `GET /api/v2/finance/invoice-stock-sources`，同时要求 `finance:view`、`finance:invoice` 的现有 ALL 范围权限。查询关联当前组织的已过账入库/发货、对应订单行和启用往来方；返回真实头/行ID、订单号、交易方、商品、币种及原订单价格/折扣/税率。

数量口径沿用现有发票过账规则：采购accepted_quantity、销售delivery.quantity，减去POSTED正式发票来源数量并按原发票行贷记比例释放；草稿不预占。页面仅列本位币且剩余大于0的候选，允许分批数量，按原订单条款生成一行发票和一条来源关联。本批每次一条来源，不含异常匹配审批或多行合并编辑。后端创建/过账规则与迁移未改变，过账仍执行并发数量校验。

编辑器读取失败时阻止保存、提交中阻止重复保存与关闭，关闭/重开和组织变化清空选择，忽略迟到读取。保存失败先重读来源并刷新父页面，不自动重试；相同内容显式重试使用稳定Idempotency-Key，内容变化生成新键。

实际走查发现销售单默认USD且无币种说明，导致CNY组织的发货不进入本位币候选。本批同时修正：新建手工销售订单/报价读取组织本位币并明确显示；选择有效报价沿用其币种，清除来源或重开恢复本位币；读取失败禁建。未提供完整外币/汇率编辑，也未更改已有订单币种。
