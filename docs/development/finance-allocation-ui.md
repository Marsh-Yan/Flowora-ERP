# 收付款核销页面验证

R5第二十批（2026-10-05）接入现有核销与撤销接口，不改变后端或迁移。

已过账的普通收款/付款提供核销管理入口，包括已经全部核销的单据。需要 finance:view 与 finance:allocate，沿用组织 ALL 数据范围。打开弹窗重新读取当前收付款、发票及核销记录；候选发票不受父列表日期区间限制，只包含同交易方、同币种、已过账且未结的对应销售/供应商发票。退款与贷项单不在本批页面操作范围。

核销上限是收付款可用余额与发票总额减已核销、已贷记金额的较小值。禁止无效金额及重复点击。撤销需要原因，保留历史记录，同一次撤销重试沿用幂等键。核销创建接口没有幂等键，页面不会自动重试写入；任何写入结果后重新读取余额与历史并通知父页面刷新，响应失败时提示先检查刷新结果再决定操作。
