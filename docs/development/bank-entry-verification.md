# 银行账户与流水录入验证

R5第二十一批（2026-10-05）补齐银行对账前置录入。既有页面只有流水列表，收付款不能选择银行账户。

新增 GET /api/v2/finance/bank/accounts，只返回当前组织启用账户的ID、编码、名称、币种；要求现有 finance:view 及 ALL 数据范围，不返回银行账号。收付款单可选本位币账户，留空沿用现金；读取失败时禁止选择银行账户，现金仍可保存。流水列表显示账户和币种。

finance:view 与 finance:bank 权限下可手工录入一条流水：选择启用账户、有效交易日期、非零带方向金额、最多160字符的参考号。币种来自账户；收款正数、付款负数。沿用现有导入契约，同组织同银行账户的重复参考号被忽略，不用于修改原流水。失败保留输入并刷新列表，提示检查结果，不自动重试写入。表单在账户加载完成后渲染，并在提交状态切换时重建输入，避免加载阶段留下不可编辑状态。
