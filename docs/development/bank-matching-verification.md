# 银行匹配与撤销页面验证

验证日期：2026-10-05。基线为 PR46 合并后的 main `835b07a643bd3cf6ba89de7bc6eadd8bf1159e03`。本批补齐财务中心的对账管理入口，支持一条完整流水匹配一张收付款单，同一收付款可被多条流水分笔匹配。

## 规则与接口

页面同时要求 `finance:view` 和 `finance:bank` 的现有 ALL 范围权限。候选覆盖全部日期，只接受已过账、同账户、同币种、同方向且剩余金额足够的收付款；正向流水对应收款/供应商退款，负向对应付款/客户退款。剩余金额仅扣除 CONFIRMED 匹配，REVERSED 历史不占用余额。

既有创建/撤销写接口与数据库迁移未修改。对账读取 DTO 新增 links（流水行 ID、收付款 ID、匹配金额），按当前组织和对账 ID 查询，保留撤销历史。缺失 links 或读取失败时停止操作，提供显式重新加载。

创建沿用 Idempotency-Key；选择不变的显式失败重试保留同一个键，选择改变后生成新键。撤销沿用无幂等键契约，原因去除首尾空白后必填且最多500字符。所有写入成功或失败后重读当前状态与历史并刷新父页面，禁止自动写入重试；提交中阻止重复提交与关闭。
