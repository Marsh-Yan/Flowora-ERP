# 登录保留槽与会话轮换（R5-I，2026-10-02）

local/production 使用共享 Redis 索引会话。登录的分布式锁和临时保留槽共同限制同一账号最多三个已保存或正在创建的会话；v1/v2 登录都经过同一规则。不扩大上限，不自动踢出其他会话。

此前请求结束前添加的保留槽会保留30秒。切换组织更换会话ID后，注销清理当前ID，旧登录ID却可能仍占槽；隔离实证三次登录/切换/注销后留下1/2/3个槽，第四次登录409。v1注销和重新登录的轮换也必须使用相同完成规则。

`LoginReservationFilter` 的顺序位于 `SessionRepositoryFilter` 外侧。成功取得登录占位时记录该请求的账号与会话ID；Spring Session 完成请求并保存索引后，仅在该账号的索引确实包含同一个ID时清理对应占位。正在处理和未保存的登录仍占容量，不在控制器返回时提前释放。与下一次登录交错时，已保存会话在索引中计数；原互斥锁和去重规则继续生效。

索引不可确认、保存失败或清理失败时保留有界30秒TTL，不把存储故障当作已成功清理。清理失败记录通用日志，不覆盖原响应或原异常，也不输出账号、会话ID、凭据或底层异常信息。过滤器只在local/production注册；standalone 没有共享存储，仍只作为诊断环境。没有新迁移、全局Redis键清理或历史会话批量撤销。
