# Flowora ERP 2.0 财务与项目核算开发规则

## 范围

M4 在 1.0 基础财务之上引入正式发票、红字单据、收付款核销、完整冲销、期间管控、银行对账、多币种重估、预算执行与项目计费。M3 业务单据仍是事实来源，财务单据不得反向改写库存或履约数量。

## 日期与金额口径

每张财务单据分别保存业务日期、会计日期、汇率日期和到期日。交易币种金额、基础币种金额与汇率在创建时固化；所有金额按四位小数保存。会计日期决定期间，关闭期间禁止新增过账。

## 发票与匹配

- 销售发票引用销售出库行或项目计费依据；供应商发票引用采购入库行。
- 红字单据必须引用原已过账发票，并校验累计红冲金额和数量不得超过剩余值。
- 供应商发票比较订单价格、入库数量与发票税额；超过组织容差时进入异常状态，需具备例外审批权限后方可过账。
- 创建接口要求幂等键；同组织同键重放必须返回同一单据。

## 总账与期间

自动凭证由语义过账映射解析科目。每张凭证必须至少两行、借贷互斥、交易币与基础币分别平衡。已过账凭证不可编辑，只能创建反转凭证。期间关闭保存检查项和结果；重新打开必须记录原因、操作者和请求键。

## 收付款与银行对账

收付款过账后才能核销。核销必须满足组织、往来方和币种一致，且不能超过付款或发票剩余金额；核销可反向撤销并保留审计记录。银行流水以账户和外部参考号去重，对账记录保存流水、付款、匹配金额和差额，撤销后恢复流水未匹配状态。

## 项目计费与利润

项目支持固定价、里程碑、工时材料三种计费模式。工时、费用和里程碑经审批后生成不可超额消费的计费依据；生成项目发票仅创建草稿，仍由财务人员复核过账。利润视图分开展示合同额、待计费、已开票、已过账收入、已过账成本、管理工时成本和毛利。

## 月结演练顺序

1. 清理匹配异常和未过账正式发票。
2. 完成收付款核销并处理未匹配银行流水。
3. 执行外币余额重估并复核重估凭证。
4. 检查试算平衡与预算执行差异。
5. 执行期间关闭检查，保存检查明细。
6. 关闭期间后验证新增过账被拒绝；如需重开，必须使用独立权限并填写原因。

## 验收底线

- 交易币与基础币总账均借贷平衡；
- 幂等重放不产生重复发票、付款或凭证；
- 发票、红字、核销、反核销和银行对账均可追溯到操作者与来源；
- 项目计费依据不会被超额或重复消费；
- 演示数据可重复重置，角色权限不会残留或重复。
