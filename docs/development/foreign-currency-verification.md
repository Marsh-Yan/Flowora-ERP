# 外币发票及收付款入口验证（2026-10-07，R6-B）

基线为已合并 PR51，merge `7f0b05630a28cd05dfbcdc55a21d638a9adf6701`。后端已有外币创建、过账、核销及汇兑差额能力，普通财务创建表单此前固定使用本位币和汇率 1，缺少外币入口。

新增独立弹窗，支持销售发票、供应商发票、收款和付款。只展示组织已启用的外币与有效往来方；完整读取分页主数据，读取失败或超过分页保护上限时暂停创建。明确显示“1 单据币种 = 输入的会计汇率金额 本位币”，要求手工输入已确认的正数会计汇率（最多 8 位小数）及真实、非未来汇率日期，不自动获取市场汇率。切换币种或单据类型清空汇率，银行账户仅显示单据同币种账户，留空表示现金。

先保存草稿，再沿用既有单独过账、同币种同往来方核销入口；已实现的汇兑差额与撤销由后端既有规则入账。入口需要 finance:view、master:view 和对应 finance:invoice 或 finance:create，沿用 ALL 范围规则。保存中禁止重复保存或关闭，结果不确定时刷新数据并要求明确重试：相同内容复用请求键，内容改变使用新键。支付 API helper 新增可选显式键，既有调用保留默认行为。关闭、组织切换及卸载丢弃迟到读取。

本批为手工单行发票（折扣 0，可填税率）和普通收付款。业务及记账日期采用当天，发票到期日为当天加 30 日；不覆盖外币库存来源开票、外币贷记、期末重估、退款或回溯记账。后端写规则、迁移、权限定义、依赖和 CI 门禁未改变，后端仍负责最终业务及并发校验。
